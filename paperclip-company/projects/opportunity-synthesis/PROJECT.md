# Sintesis Semanal de Oportunidades

Cada viernes, el CEO lidera la sintesis de todas las senales acumuladas durante la semana.

## Cadencia
- **Semanal** (viernes 10:00 CET)

## Participantes
- Elena Voss (CEO) — lidera
- Carmen Solis (Brand Expert) — contrasta vs portfolio 35mm
- Marcos Aldana, Lucia Ferrer, Daniel Ruiz (Heads) — aportan consolidados

## Proceso
1. Revisar notas diarias de la semana
2. Identificar clusters de skills en multiples fuentes
3. Validar cada cluster (minimo 3 fuentes para "solido")
4. Estimar TAM por cluster
5. Clasificar oportunidades vs portfolio 35mm.es
